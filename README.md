# EmulatorPSW7

Эмулятор источников питания с поддержкой SCPI-команд, графическим интерфейсом и хранением истории.

## Возможности
- Поддержка двух приборов: GW Instek PSW7-800 и Keysight E36312A (с поддержкой каналов).
- Три сетевых протокола: TCP, UDP, HTTP.
- Графический интерфейс для ручного ввода команд и просмотра истории.
- Импорт команд из текстового файла по любому из протоколов.
- Автоматическое сохранение истории в базу данных SQLite.
- Автообновление истории в интерфейсе каждые 2 секунды.
- Полная документация API и автоматическая сборка через GitHub Actions.

## Системные требования
- ОС: Windows 10 или 11 (64-bit).
- Компилятор: Visual Studio 2022 (MSVC).
- CMake: версия 3.16 или выше.
- Qt: версия 6.10.2 (msvc2022_64).

Откройте Developer Command Prompt for VS 2022 и выполните:
