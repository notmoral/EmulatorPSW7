# EmulatorPSW7

Эмулятор лабораторных источников питания с поддержкой SCPI-команд, графическим интерфейсом и хранением истории.

## Возможности
- Поддержка трех приборов: GW Instek PSW7-800, Keysight E36312A (3 канала) и Rigol DP832 (3 канала).
- Четыре сетевых протокола: TCP, UDP, HTTP и WebSocket (для мгновенных уведомлений).
- Графический интерфейс (GUI) для ручного ввода команд, поиска и фильтрации истории.
- Импорт команд из текстового файла и экспорт истории в форматы CSV/JSON.
- Автоматическое сохранение истории в базу данных SQLite.
- Поддержка Docker (Headless-режим для запуска на серверах без GUI).
- Полная Doxygen-документация и автоматическая сборка (CI/CD) через GitHub Actions.

## Физическая модель и защита
- **Закон Ома:** Эмулятор рассчитывает ток и напряжение в зависимости от сопротивления нагрузки (режимы стабилизации напряжения CV и тока CC).
- **Защита OVP:** Поддержка защиты от перенапряжения (`VOLTage:PROTection:STATe`), которая автоматически сбрасывает лимиты при превышении допустимых значений.
- **Очередь ошибок:** Поддержка стандартной SCPI-команды `SYSTem:ERRor?` для чтения ошибок (неверные команды, превышение лимитов).

## Системные требования
- ОС: Windows 10 или 11 (64-bit), либо Linux (для Docker).
- Компилятор: Visual Studio 2022 (MSVC) или GCC.
- CMake: версия 3.16 или выше.
- Qt: версия 6.10.2 (msvc2022_64).
